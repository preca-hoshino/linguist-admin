# src/i18n/locales — 语言翻译资源

> 父模块：[`src/i18n/README.md`](../README.md)
>
> 项目总览：参见 [README.md](../../README.md)

## 简介

存放所有语言的翻译键值映射文件。每种语言对应独立的 TypeScript 模块，以结构嵌套的对象表示，所有语言文件须保持**完全相同的键结构**，英文（`en.ts`）作为类型锚点。

## 目录结构

```
locales/
├── en.ts       # 英文翻译（类型推断基准）
└── zh-CN.ts    # 简体中文翻译
```

## 核心接口

| 文件 | 说明 |
| --- | --- |
| `en.ts` | 英文键值对象，导出为 `const`（TS 类型严格推断） |
| `zh-CN.ts` | 中文键值对象，键结构与 `en.ts` 保持一致 |

## 新增 / 重构 / 删除向导

### 新增语言文件

1. 新建 `<locale>.ts`，内容结构完全对照 `en.ts` 复制后翻译；
2. 返回父模块 `index.ts` 在 `resources` 中注册该语言。

### 修改翻译

- 直接更改对应语言文件中的字符串值。
- **不得改变键名**（否则须同步所有语言文件及代码引用处）。

### 删除翻译键

- 同步删除全部语言文件内的对应键，并通过 `npm run type-check` 确认无遗留引用。
