## 简介

提供系统数据的导入/导出入口页面。此为轻量的单文件视图，作为数据迁移、原始数据离线导出等工具性功能的 UI 入口，结构保持简单。

## 目录结构

```
data/
└── index.tsx     # 数据导出功能的主视图页面
```

## 核心页面

| 文件 | 路由路径 | 说明 |
| --- | --- | --- |
| `index.tsx` | `/data` | 数据功能入口页，提供数据导出等操作的触发界面 |

## 设计规范

- **轻量原则**：此模块当前为功能性单页面，若未来功能扩展，按需从相近模块（如 `models/`）借鉴就近组件拆分规范。
- **操作安全**：数据导出等破坏性操作须通过 `AlertDialog` 做二次确认，防止误操作。

## 新增 / 重构 / 删除向导

### 扩展数据功能

1. 若新增数据功能（如数据导入、日志归档），视复杂度在 `index.tsx` 中扩展或在目录下新建对应 `.tsx` 文件；
2. 功能组件复用需求出现时，在此目录新建 `components/` 子目录（参照 `dashboard/` 的组织方式）。

### 重构

- 若 `index.tsx` 体积增大，将表单/操作块拆分为 `components/` 目录下的独立组件。

### 删除

- 整体废弃此功能时，同步删除 `src/router/_authenticated/data/` 下的路由文件，并移除侧边栏导航数据（`layouts/data/sidebar-data.ts`）中的对应条目。
